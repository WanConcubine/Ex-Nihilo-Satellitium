# 纹理规范

> 状态：M1（木桶 + 瓷土）／最后更新：2026-10-27

## 风格

- **16×16**（方块与物品），1px 深色描边，无抗锯齿，左上光源，低饱和。
- 每种材质 4–6 个色阶；避免大面积纯黑/纯白。
- 对标 1.20 原版：干净、可读、克制，不追求写实噪点。
- 放大看结构要成立（16×），进游戏看整体（4× 截图）。

## 文件与命名

```
assets/exnihiloimitatio/textures/
├── block/
│   ├── barrel_side.png      # 外壁：桶板 + 两道铁箍
│   ├── barrel_top.png       # 顶沿（1px 宽，会被压扁）
│   ├── barrel_inner.png     # 内壁 + 桶底内侧
│   ├── barrel_bottom.png    # 外底
│   └── barrel_compost.png   # 堆肥表面
└── item/
    └── porcelain.png        # 瓷土
```

模型里的贴图引用**必须**是 `exnihiloimitatio:`，禁止 `minecraft:`。
原版方块/物品贴图只允许作为 `parent`（例如 `minecraft:item/generated`），
不允许作为 `layer0` 或面贴图。

## AI 政策

- **不把 AI 生图直接放进 release。**
- 当前所有像素由 `art/barrel/generate.py` 与 `art/items/generate.py` 逐像素生成，
  可复现、可审阅；也可由画师手绘后替换同名文件。
- moodboard / 参考图可以用 AI，但**不进仓库**、不参与打包。
- 每个新贴图在 PR/提交里注明来源（脚本或画师）。

## 检查

```bash
python3 scripts/check-textures.py
```

会失败的情况：

- 模型纹理层还指向 `minecraft:*`；
- 引用了不存在的 `exnihiloimitatio:*` 贴图；
- PNG 不是 16×16。

这个检查是“能打脸”的：改坏任何一条都会红。

## 评审流程

1. 16× 放大看结构（`art/barrel/barrel_side_16x.png`）。
2. 3D 预览：`python3 art/barrel/render3d.py` → `art/barrel/render_3d.png`。
3. 进游戏 4× 截图，和原版方块放一起看整体。
4. 通过后再进 `assets/`、再提交。
