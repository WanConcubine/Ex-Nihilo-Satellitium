# 无中生有（Ex Nihilo 1.7.10）基础知识

> 用途：写玩法/数值前先对齐“原版到底怎么运作”。事实来源：`reference/ex-nihilo-original`
> 的**只读对照**（GPLv3，不复制代码/资源）＋公开 Wiki/实况。每条标注**已确认**或**待核**，
> 待核项在进游戏实测前不要写进数值表。

## 0. 它解决什么问题

空岛只有一棵树和一点土。Ex Nihilo 提供一整套**把“无”变成“有”**的机器：
堆肥造土、筛子出矿、锤子碎矿、坩埚熔岩、钩子取苗、蚕吐丝。
本质是**资源生成框架**：它自己几乎不产矿，靠开放的筛子/桶/坩埚表把别的模组的材料接进来。

## 1. 核心循环

```
树 → 木头 → 工作台 / 木桶
木桶 + 有机物 ──堆肥──→ 泥土
泥土 / 砂砾 / 沙子 ──筛子──→ 种子、矿粒、宝石、杂物
圆石 ──锤子──→ 砂砾 ──锤子──→ 沙子 ──锤子──→ 尘土
树叶 ──钩子──→ 树苗 / 苹果 / 蚕
蚕 ──放回树叶──→ 侵染树叶 ──破坏──→ 丝线
坩埚 + 热源 + 圆石 ──→ 熔岩
瓷土 ──→ 瓷桶（能装熔岩）
```

## 2. 木桶（Barrel）

- **容量**：1000 mB 流体；**堆肥满值 → 成土**耗时 **1000 tick（50 秒）**。*（已确认：`TileEntityBarrel` 的 `MAX_FLUID` / `MAX_COMPOSTING_TIME`）*
- **堆肥值**：原版是 **0..1 的小数**，树苗/树叶 = **0.125**（即 8 个成一块土）。*（已确认：`CompostRegistry`）*
  本项目改成 1000 分制，树苗 125，等价于同一比例。
- **接雨水**：露天的桶会随时间接雨水补满。*（已确认：`TileEntityBarrel` 有按 biome rainfall 累加的代码）*
- **桶内配方**（把物品丢进指定流体里转化，全部有配置开关）：*（已确认：`TileEntityBarrel` 的 `BarrelMode` 分支）*
  | 流体 | 投入 | 产出 |
  |---|---|---|
  | 水 | 萤石粉 | 末地石 |
  | 水 | 愤怒娃娃 | 烈焰棒（`BLAZE_COOKING`）|
  | 巫水 | 沙子 | 灵魂沙 |
  | 巫水 | 诡异娃娃 | 末影珍珠 |
- **巫水（Witch Water）**：原版确实有这种流体和桶（`FluidWitchWater` + `ItemBucketWitchWater`）。
  **怎么产生：待核**——源码里只看到“巫水里放什么”，没确认“水怎么变成巫水”，需要实测或查 Wiki。
- **石桶**：原版有独立方块 `BlockBarrelStone`；具体差异（是否只装熔岩/耐熔岩）**待核**。
  本项目目前七种桶共享一个 BE，石桶暂未差异化。

## 3. 筛子（Sieve）与筛网（Mesh）

- 筛子放在地上，手持材料右键反复筛；不同**筛网**决定能筛什么、掉率好坏。*（已确认有筛子方块与网物品；具体档位待核）*
- 掉落表按“筛料 + 网档”分开，1.7.10 里是代码注册（`SieveRegistry.register(block, item, meta, rarity)`），
  `rarity` 的语义是 **`1/N`**（`rand.nextInt(rarity) == 0`）。*（已确认）*
- 本项目把这张表数据化；`rarity` 仍按 `1/N` 解释。

## 4. 锤子（Hammer）与钩子（Crook）

- 锤子：**圆石 → 砂砾 → 沙子 → 尘土**；也能把矿物方块锤成碎料。*（已确认：`HammerRegistry` + 矿链注册）*
- 钩子：破坏树叶时提高树苗/蚕的掉率。木钩 / 骨钩两档。*（已确认有两档物品）*

## 5. 蚕（Silkworm）

- 蚕放到树叶上 → 树叶变成**侵染树叶**（`BlockLeavesInfested`），破坏后掉丝线。*（已确认方块存在；流程细节待核）*
- 蚕有生/熟两种（`ItemSilkworm` / `ItemSilkwormCooked`，熟的应该是食物）。

## 6. 坩埚（Crucible）

- 未烧制的坩埚（`BlockCrucibleUnfired`）烧成坩埚；坩埚靠**下方热源**把圆石熔成熔岩。*（已确认存在，热源判定待核）*
- 原版坩埚有“上方是否有天空/雨”的加速之类细节，**待核**。

## 7. 瓷土与瓷桶

- 瓷土球（`ItemPorcelainBall`）→ 烧制 → 瓷桶。瓷桶能装熔岩（普通桶不行）。*（已确认物品存在；瓷桶具体 id 待核）*

## 8. 矿物链（本项目已实现的部分）

每种材料一套自有物品，而不是直接吐对方原矿：

```
筛 砂砾 → 破碎矿   筛 沙子 → 粉碎矿   筛 尘土 → 粉末
破碎 ×4 → 矿砾方块  粉碎 ×4 → 矿砂方块  粉末 ×4 → 矿尘方块
锤 矿砾 → 粉碎矿    锤 矿砂 → 粉末    （原矿方块 → 破碎矿）
熔炼 矿砾 / 矿砂 / 矿尘 → 锭
```

原版实现里每种矿带一个 `Color`，贴图在运行时用 `Base + Template + Color` 合成；*（已确认）*
这也是为什么“矿砾/矿砂/矿尘方块”能共用一套几何却各有颜色。

## 9. 娃娃（Dolls）

原版有多个娃娃物品（愤怒/诡异等），在桶内配方里代替稀有材料。*（已确认 `ENItems.DollAngry` 等）*
本项目暂未列入 M1–M9，属于后续内容。
