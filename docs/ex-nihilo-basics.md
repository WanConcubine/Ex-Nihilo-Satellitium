# 无中生有（Ex Nihilo 1.7.10）基础知识

> 用途：写玩法/数值前先对齐“原版到底怎么运作”。事实来源：`reference/ex-nihilo-original`
> 的**只读对照**（GPLv3，不复制代码/资源）＋公开 Wiki/实况。每条标注**已确认**或**待核**，
> 待核项在进游戏实测前不要写进数值表。

## 0. 它解决什么问题

空岛只有一棵树和一点土。Ex Nihilo 提供一整套**把“无”变成“有”**的机器：
堆肥造土、筛子出矿、锤子碎矿、坩埚熔岩、钩子取苗、蚕吐丝。
本质是**资源生成框架**：它自己几乎不产矿，靠开放的筛子/桶/坩埚表把别的模组的材料接进来。

## 1. 核心循环

```
树 → 木头 → 工作台 / 木桶
木桶 + 有机物 ──堆肥──→ 泥土
泥土 / 砂砾 / 沙子 ──筛子──→ 种子、矿粒、宝石、杂物
圆石 ──锤子──→ 砂砾 ──锤子──→ 沙子 ──锤子──→ 尘土
树叶 ──钩子──→ 树苗 / 苹果 / 蚕
蚕 ──放回树叶──→ 侵染树叶 ──破坏──→ 丝线
坩埚 + 热源 + 圆石 ──→ 熔岩
瓷土 ──→ 瓷桶（能装熔岩）
```

## 2. 木桶（Barrel）

- **容量**：1000 mB 流体；**堆肥满值 → 成土**耗时 **1000 tick（50 秒）**。*（已确认：`TileEntityBarrel` 的 `MAX_FLUID` / `MAX_COMPOSTING_TIME`）*
- **堆肥值**：原版是 **0..1 的小数**，树苗/树叶 = **0.125**（即 8 个成一块土）。*（已确认：`CompostRegistry`）*
  本项目改成 1000 分制，树苗 125，等价于同一比例。
- **接雨水**：露天的桶会随时间接雨水补满。*（已确认：`TileEntityBarrel` 有按 biome rainfall 累加的代码）*
- **桶内配方**（把物品丢进指定流体里转化，全部有配置开关）：*（已确认：`BlockBarrel` + `TileEntityBarrel`）*
  | 流体 | 投入 | 产出 | 模式 |
  |---|---|---|---|
  | 水 | 尘土 | 粘土块 | `CLAY` |
  | 水 | 牛奶桶 | 粘液球 ×1–4（非和平会生成史莱姆） | `MILKED` → `SLIME` |
  | 熔岩 | 红石 | 下界岩 | `NETHERRACK` |
  | 熔岩 | 荧石粉 | 末地石 | `ENDSTONE` |
  | 熔岩 | 愤怒娃娃 | 烈焰人（和平模式可抽出烈焰棒） | `BLAZE_COOKING` → `BLAZE` |
  | 巫水 | 沙子 | 灵魂沙 | `SOULSAND` |
  | 巫水 | 诡异娃娃 | 末影人（和平模式可抽出末影珍珠） | `ENDER_COOKING` → `ENDER` |
  | 巫水 | 橡树苗 | 深色橡树苗 | `DARKOAK` |

- **巫水（Witch Water）**：原版确实有这种流体和桶（`FluidWitchWater` + `ItemBucketWitchWater`）。
  **产生方式（源码）**：满水的桶，附近有**菌丝**（`getNearbyBlocks(Blocks.mycelium)`）会进入 `SPORED`，
  计时后整桶变成巫水；把**蘑菇煲**或**孢子（Spores）**直接丢进满水桶也会进入 `SPORED`。
  本项目要把巫水做成自定义流体，留到 M6。
- **石桶**：原版有独立方块 `BlockBarrelStone`；**差异已确认（Sequentia）**：木桶不能装
  温度 > 433 K 的流体（水 300 K、熔岩 1300 K），石桶可以。本项目已按这个阈值实现。
- **凝固**：满水桶 + 熔岩（或上方熔岩源）→ 圆石；满熔岩桶 + 水 → 黑曜石。*（Sequentia 页面确认）*
- **掺料**：满熔岩 + 红石 → 下界岩；+ 荧石粉 → 末地石；满水 + 尘土 → 粘土块；
  满水 + 牛奶桶 → 史莱姆。*（源码 + Sequentia 页面；本项目已接 `water_dust_clay.json`）*
- **雨水**：露天桶按降雨量积水。*（原版源码 + Sequentia 页面都确认）*

## 3. 筛子（Sieve）与筛网（Mesh）

- 筛子放在地上，手持材料右键反复筛；不同**筛网**决定能筛什么、掉率好坏。*（已确认有筛子方块与网物品；具体档位待核）*
- 掉落表按“筛料 + 网档”分开，1.7.10 里是代码注册（`SieveRegistry.register(block, item, meta, rarity)`），
  `rarity` 的语义是 **`1/N`**（`rand.nextInt(rarity) == 0`）。*（已确认）*
- 本项目把这张表数据化；`rarity` 仍按 `1/N` 解释。

## 4. 锤子（Hammer）与钩子（Crook）

- 锤子：**圆石 → 砂砾 → 沙子 → 尘土**；也能把矿物方块锤成碎料。*（已确认：`HammerRegistry` + 矿链注册）*
- 钩子：破坏树叶时提高树苗/蚕的掉率。木钩 / 骨钩两档。*（已确认有两档物品）*

## 5. 蚕（Silkworm）

- 蚕右键**树叶** → 该方块变成**侵染树叶**（`BlockLeavesInfested`，BE 记住原树叶外观）；
  进度满后向相邻树叶扩散；破坏侵染树叶掉 **线（`Items.string`）**。
- 蚕有生/熟两种：`ItemSilkworm` 用来感染树叶；`ItemSilkwormCooked` 是食物
  （`ItemFood(2, 10.0f)`，可直接烤）。

## 6. 坩埚（Crucible）

- 未烧制坩埚（`BlockCrucibleUnfired`）烧成坩埚；坩埚靠**正下方热源**把方块熔成流体。*（源码：`HeatRegistry`）*
- 热源（`HeatRegistry.registerVanillaHeatSources`）：

  | 方块 | 速度 |
  |---|---|
  | 火把 | 0.1 |
  | 熔岩 | 0.2 |
  | 流动熔岩 | 0.1 |
  | 燃烧的熔炉 | 0.15 |
  | 火 | 0.3 |

- 可熔物（`CrucibleRegistry`）：圆石 / 石头 / 砂砾 2000 固体 → 250 mB 熔岩；
  下界岩 2000 → 1000 mB 熔岩；雪 2000 → 500 mB 水；冰 2000 → 1000 mB 水。
- 1.7.10 的坩埚**没有**“露天 / 下雨加速”；那是别的版本或附属的设定。

## 7. 瓷土、娃娃与瓷桶

- 瓷土球（`ItemPorcelainBall`） = **粘土球 + 骨粉**（无序合成）。
- **7 个瓷土** → 未烧制坩埚（`x x` / `x x` / `xxx`），烧制后就是坩埚。
- 瓷土 + 钻石 / 绿宝石 → 娃娃（`Doll`）；娃娃 + 烈焰粉/下界疣/红石/荧石 → 愤怒娃娃；
  娃娃 + 墨囊/青金石 → 诡异娃娃。
- **1.7.10 没有“瓷桶”**；瓷桶是 Sequentia / Omnia 的设定（能装熔岩）。
  本项目 parity 里的“瓷桶”按 Sequentia 设计走，不当作 1.7.10 原版内容。

## 8. 矿物链（本项目已实现的部分）

每种材料一套自有物品，而不是直接吐对方原矿：

```
筛 砂砾 → 破碎矿   筛 沙子 → 粉碎矿   筛 尘土 → 粉末
破碎 ×4 → 矿砾方块  粉碎 ×4 → 矿砂方块  粉末 ×4 → 矿尘方块
锤 矿砾 → 粉碎矿    锤 矿砂 → 粉末    （原矿方块 → 破碎矿）
熔炼 矿砾 / 矿砂 / 矿尘 → 锭
```

原版实现里每种矿带一个 `Color`，贴图在运行时用 `Base + Template + Color` 合成；*（已确认）*
这也是为什么“矿砾/矿砂/矿尘方块”能共用一套几何却各有颜色。

## 9. 娃娃（Dolls）

原版有多个娃娃物品（愤怒/诡异等），在桶内配方里代替稀有材料。*（已确认 `ENItems.DollAngry` 等）*
本项目暂未列入 M1–M9，属于后续内容。
